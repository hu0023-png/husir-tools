🌈 Color Code Converter

HEX ↔ RGB ↔ HSL · alpha supported · runs 100% in your browser

📘 About this tool

One color, many spellings. A purple picked in Figma comes out as #764BA2; the same color in CSS might need rgb(118, 75, 162), and tweaking it — making it a bit lighter without changing the hue — is far easier in hsl(270, 37%, 46%). This converter accepts any of those formats, shows the color on a live swatch, and writes all three representations with one click to copy.

Paste a code from any tool, type one directly, or use the color picker to explore. HEX and RGB are the same 0–255 red/green/blue model in different notation; HSL describes the same color by hue (0–360°), saturation, and lightness, which matches how humans think about color. Alpha is supported in every direction (#RRGGBBAA, rgba(), hsla(), and modern space syntax such as rgb(0 0 0 / 50%)). All conversion happens locally on your device — nothing is uploaded, and the page works offline.

💡 Why convert to HSL?
HSL splits a color into hue, saturation, and lightness, so you can lighten or darken a palette, raise saturation, or generate tints of a brand color without guessing at RGB numbers.

🎨 Which formats are accepted?
#RGB, #RRGGBB, 4/8-digit hex with alpha, rgb()/rgba(), hsl()/hsla(), percentages, and modern space syntax like rgb(118 75 162 / 0.5).

🔄 Will my color change when converted?
Only within 8-bit rounding: HEX stores each channel as 0–255, so conversions may differ by 1 unit in a channel from the original decimal. Visually indistinguishable in practice.

📖 What about CSS names like “red”?
Named colors are not parsed here. Use the color picker or paste the HEX/RGB/HSL value from your editor to convert a specific named color.

🔒 Does this tool upload my colors?
Never. Parsing and conversion run entirely in your browser with zero network calls.

📐 Quick reference
HEX pair → decimal: FF = 255  ·  #764BA2 = rgb(118, 75, 162)
HSL uses hue 0–360°, saturation/lightness 0–100%
L = (max + min) / 2  ·  S = Δ / (1 − |2L − 1|)  ·  hue steps by channel: 0° red, 120° green, 240° blue
