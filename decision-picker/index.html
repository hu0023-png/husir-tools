🎯 Decision Picker

Random picker with weights · raffle mode · runs 100% in your browser

📘 About this tool

Type your options — one per line — hit “Pick one”, and let this page make the call. Use it for deciding where to eat, whose name to draw for a giveaway, which task to start first, or what movie to watch. Every option has equal odds by default; to bias the draw, append a weight: Pizza | 3 is three times more likely than an unweighted option.

Raffle mode removes each winner after the pick, so a list of names produces a unique random ordering with no repeats — perfect for door-prize drawings, classroom turns, or choosing who presents first. A session tally shows how often each option has been chosen, and a short history shows recent results. Randomness comes from the browser’s secure random source; everything runs locally, so nothing about your choices is uploaded.

⚖️ How do weights work?
Each option counts toward a total: unweighted options count as 1, Name | 3 counts as 3. One weighted entry is picked at random — so with options A and B|3, B wins 3 out of 4 draws.

🎲 Is the randomness fair?
Yes — draws use crypto.getRandomValues, the same secure source used for passwords. Each draw is independent and unbiased.

🔁 Can two people pick the same winner?
By default yes (drawn with replacement). Turn on “Remove picked option” for raffle style: each option can win only once until the list is empty.

📋 Where does the tally come from?
Counts track every pick made in this browser session, so you can see whether results look fair over many draws. It resets when you clear or reload with a fresh list.

🔒 Is my list uploaded?
Never. Options are read and randomized entirely on your device with zero network calls.

📐 How it works
Total weight = Σ option weights (unweighted = 1)
Draw = random in [0, total) → the option whose cumulative weight crosses that point wins
Odds of an option = its weight ÷ total weight × 100%
