# HuSir Tools — 75 free browser tools that never upload your files

Everything here runs **in your browser**. The file you open is never uploaded, there is no account,
no tracking — and the whole set works with **no internet at all**.

- **Web version:** https://www.husir.org/tools/
- **Offline ZIP:** see [Releases](../../releases) — unzip, open `index.html` (or `Start Here.html`), done.
- **Privacy claim, and how to verify it yourself:** https://www.husir.org/tools/no-upload/

## What's in the box

Each tool is **one self-contained HTML file** — no build step, no dependencies, no server.
Open it, use it, close it. Categories:

- **PDF** — merge/split, compress, convert, sign (signature module included)
- **Images** — compress, convert, resize, crop, ID photo makers
- **QR codes** — single, batch, Wi-Fi, dynamic
- **Classroom** — seating chart, random groups, attendance, quiz/flashcard maker, grade stats,
  parent notes, rubrics, timers, certificates
- **Money & numbers** — US tax estimates, budget/401k calculators, invoice & W-9 generators
- **Utilities** — case converter, base64, date calculators, decision picker, meeting minutes

## How to verify the no-upload claim

1. Open any tool. 2. Open your browser's developer tools → **Network** tab. 3. Use the tool.
You will see no request carrying your file. That page walks through it step by step.

## Run it yourself

Download the ZIP from Releases, or just download this repo and open the HTML files directly.
Nothing needs to be installed or compiled.
