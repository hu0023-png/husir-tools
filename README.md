# HuSir Tools — 75 free browser tools that never upload your files

Everything here runs **in your browser**. The file you open is never uploaded, there is no account,
no tracking — and the whole set works with **no internet at all**.

- **Web version:** https://www.husir.org/tools/
- **Offline ZIP:** see [Releases](../../releases) — unzip, open `index.html`, done.
- **Privacy claim, and how to verify it yourself:** https://www.husir.org/tools/no-upload/

Each tool is **one self-contained HTML file**: no build step, no dependencies, no server. Open it, use it, close it.

## How to verify the no-upload claim

1. Open any tool. 2. Open your browser's developer tools → **Network** tab. 3. Use the tool.
You will see no request carrying your file. [That page](no-upload/) walks through it step by step.

## Run it yourself

Download the ZIP from [Releases](../../releases), or just download this repo and open the HTML files directly.
Nothing needs to be installed or compiled. Keep the folder together — the "You may also like" links between tools are relative paths.
