🔗 URL Encoder & Decoder

Percent-encode & decode · query-string aware · runs 100% in your browser

📘 About this tool

A URL may only contain a limited set of ASCII characters. Spaces, Chinese characters, emoji, and punctuation such as &, =, #, or % must be “percent-encoded” before the URL is sent. This tool encodes and decodes text entirely in your browser: type a value to see its encoded form, or paste an encoded string to read the original text.

Typical uses: preparing query parameters for an API, building a link that contains Chinese or emoji, converting a filename with spaces into a download link, or decoding tracking URLs and analytics links to see what they really contain. The encoder follows the component rules used by encodeURIComponent (a space becomes %20; reserved characters like & and = are escaped). Nothing is uploaded — the page works offline with zero network calls.

❓ What is the difference between %20 and +?
In URL paths, a space is %20. In query strings (?q=…), some systems also accept + as a space. This page encodes spaces as %20; when decoding you can optionally convert + back to a space.

🌍 Will Chinese, emoji, or accents work?
Yes. Each character is turned into UTF-8 bytes, then each byte becomes %XX. “你好🌍” becomes %E4%BD%A0%E5%A5%BD%F0%9F%8C%8D.

🔒 Why are reserved characters escaped?
Characters like &, =, ?, and # split a URL into parts. If a search value contains them, they must be escaped or the server will misread the query string.

🔁 Should I encode a whole URL at once?
Usually not. Encode the path segment and each parameter value separately, keeping the ://, ?, &, and = separators intact. This tool encodes a single component, so it is perfect for that job.

⚠️ Why does decoding leave some % unchanged?
Malformed escapes such as %ZZ or an incomplete %E4 cannot be converted; this page keeps them as-is and flags the error instead of producing broken text.

🛠️ Does this tool open or track my links?
Never. Encoding and decoding happen locally on your device, and the page makes no network requests.
