🔐 File Hash Checker

Verify files with SHA-1 / SHA-256 / SHA-384 / SHA-512 · runs 100% on your device

📘 About this tool

Before you install a downloaded program or open a large file, the publisher often provides a checksum — a long string like e3b0c442… that uniquely identifies the file's contents. Compute the hash here and compare it with the published value: if they match exactly, the file is complete and untouched; if not, the download is corrupted or has been tampered with.

Drag in one or more files (or click to choose), pick an algorithm, and the hash is calculated instantly. Paste the expected hash from the download page and the tool marks the result MATCH or MISMATCH, then copy the computed hash with one click for pasting into a terminal command.

All hashing is done by your browser's built-in cryptography on your own device — files are never uploaded, which matters when you are verifying installers, firmware, or sensitive documents. The page works fully offline.

📝 Which algorithm should I pick?
Use the one the publisher lists, usually SHA-256. If none is listed, SHA-256 is the best default. SHA-1 is older and weaker; only use it to match an old published value.

🔁 What does “MATCH” mean?
The computed hash equals the expected hash you pasted, character for character — the file is bit-for-bit identical to the one the publisher hashed.

🔒 Is my file uploaded?
Never. The file never leaves your device; the hash is computed locally and nothing is sent over the network.

🧭 Why no MD5?
MD5 is cryptographically broken and not available in the browser's secure crypto API. Use SHA-256 instead.

💡 Hash differs — now what?
Delete and re-download the file, then check again. If it still differs, contact the publisher and do not install the file.

📐 Quick reference
SHA-256 digest = 64 hex characters  ·  SHA-1 = 40  ·  SHA-384 = 96  ·  SHA-512 = 128
Compare lowercase, ignoring spaces: hash(a) === published  ⇒  MATCH
