🔲 Batch QR Code Generator

Generate dozens or hundreds of QR codes at once — table codes, asset tags, inventory numbers, invite codes

📘 About this tool

Generate dozens or hundreds of different QR codes from one list — perfect for table numbers, asset tags, inventory labels, check-in codes, and event invitations. Type one value per line, or use the numbering template: write something like STA-{n}, pick a start and end number, and {n} is replaced automatically (zero-padding gives STA-001, STA-002, and so on).

You can also create dynamic codes whose content lives in your own go.html file, so you can edit the text or link later without reprinting. Everything runs 100% in your browser: your list is never uploaded, keeping internal codes, URLs, and plain text private.

Static or dynamic?
Static codes embed the text or URL directly and never change. Dynamic codes store a short ID in the QR and load current content from go.html — editable later, but they need a host (instructions are on this page).

Will a plain-text QR display the text?
Yes — phone cameras show plain text, and URLs open automatically in the browser.

How do I make table numbers STA-01 through STA-50?
Use the template STA-{n} with start 1, end 50, and zero-padding 2.

Why do some codes fail after printing?
Check contrast, leave a quiet zone of four modules around the code, and use M error correction normally — Q or H for fabric, curved surfaces, or small labels.

Can I include Chinese or other characters?
Yes — the generator encodes UTF-8 text, and QR readers display it correctly.

      📤 How it works: each QR code points to a page you host yourself (go.html?id=01, id=02, …). Later you edit that page and re-upload — the printed QR codes never need to change.

      💡 A plain URL (no title / no image) opens automatically when scanned; anything else is shown as text on the page.

      🖼 One image per entry (upload it or paste with Ctrl+V) — compressed and embedded in go.html, so scanners see it on the page.

      💡 Links can have a title and image too: go.html shows them as a card with an Open-link button (WeChat blocks silent auto-redirects).
    

    

      📤 How to host go.html — step by step
      

        1. Download the file

        Click «Download full go.html» above — you get one small HTML file that already contains your content.
        


        2. Put it on any static host (pick one):
        
    
          
  • Netlify Drop — easiest, no account: open app.netlify.com/drop, drag a folder that contains go.html onto the page, and you get a public URL instantly (e.g. https://xxxx.netlify.app).
    • 
          
  • surge.sh — free, needs a one-time account:
            
      
              
    1. Install once: npm install -g surge
      2. 
              
    2. Put go.html in its own folder, e.g. dynamic-qr
      3. 
              
    3. Open a terminal and go to that folder: cd path/to/dynamic-qr, then deploy with your domain: surge . --domain your-name.surge.sh
      4. 
              
    4. First time only: surge asks for an email and password to create a free account, then publishes the folder — your page is at https://your-name.surge.sh/go.html
      5. 
              
    5. Update later: replace go.html in the folder, then re-run surge . --domain your-name.surge.sh
      6. 
            
    
          
    • 
          
  • WordPress / any web space: upload go.html to any folder you can host files in (site root, uploads, etc.) and note the URL.
    • 
        

        

          ⚠️ Where is the page? At /go.html, not at the bare domain. After deploying, open https://your-name.surge.sh/go.html — the bare domain (https://your-name.surge.sh) shows nothing because there is no index.html, which is normal.

          Never rename go.html to index.html — your QR codes point to /go.html?id=… and renaming breaks every printed code. (Optional: to let the bare domain also open your page, add a small index.html that redirects to go.html — the QR codes keep working.)
        

        

        3. Test

        Open https://your-hosted-url/go.html?id=01 in a browser (01 is the id inside your QR code). Without an id, the page lists all entries — handy for checking.
        


        4. Update content later

        Edit the CONTENTS table in go.html, re-upload the file, done. Guests scan the same QR code and see the new content.
        


        Notes: dynamic QR codes need internet when scanned; keep IDs simple (01, 02, a1, b2); if you delete an entry, its old code shows «Content not found».
