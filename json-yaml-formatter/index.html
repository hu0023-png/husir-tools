📦 JSON & YAML Formatter

Validate · pretty-print · minify · convert — runs 100% in your browser

📘 About this tool

Paste any JSON or YAML document and this tool validates it, tells you the exact line and column of a syntax error, and reformats the result. JSON can be pretty-printed with 2 or 4 spaces or minified to one line; YAML gets normalized to clean, canonical output. You can also convert between the two formats — JSON to YAML or YAML to JSON — without touching a command line.

Typical uses: cleaning up a messy API response, debugging a docker-compose.yml or GitHub Actions workflow, checking a Jekyll or Hugo front-matter block, converting config snippets between formats for different tools, and spotting duplicate keys or bad indentation before a build fails. Everything runs locally on your device — paste private configs with confidence, because nothing is uploaded and the page works offline.

💬 JSON or YAML — which should I use?
Use JSON when machines exchange data (APIs, files, databases) — it is strict and universally supported. Use YAML when humans write and read configuration (CI files, Docker, app settings) — it allows comments and reads like plain text.

⚠️ Why is my YAML invalid?
Common causes: tabs used for indentation (YAML only accepts spaces), inconsistent indentation depth, a value containing : or a leading # that was not quoted, or duplicate mapping keys. The error message points to the exact line.

📝 Will my comments survive conversion?
No. Comments are not part of the data model, so YAML → JSON drops them, and JSON → YAML never had any. Keep notes in a separate file if you need them back.

📊 Does it handle big files?
Yes, comfortably into the megabyte range. Very large documents (10 MB+) are processed locally, so they only take as long as your browser needs — nothing is throttled by a server.

🔄 Are YAML anchors and merge keys supported?
Yes. Features such as anchors (&name), aliases (*name), merge keys (<<), and multi-line strings (| and >) are parsed correctly before conversion.

🔐 Is my data sent anywhere?
Never. Parsing, formatting, and conversion happen entirely in your browser, and the page makes no network calls.

📐 Quick reference
JSON escapes: \" \\ \/ \b \f \n \r \t \uXXXX
YAML rule: spaces only — never tabs; keep child keys indented more than their parent
Same data, both forms — JSON: {"name":"HuSir","tags":["a","b"]} ↔ YAML: name: HuSir + tags: [a, b]
