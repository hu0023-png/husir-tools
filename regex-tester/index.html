🧪 Regex Tester

JavaScript regular expressions · live matches + capture groups · runs 100% in your browser

📘 About this tool

Write a regular expression, paste a block of text, and watch every match highlight live in the JavaScript flavor your code will actually use. Each match is listed with its index and capture groups, so you can verify a pattern before you ship it — validating emails, phone numbers, or log lines, extracting values from HTML or CSV, or cleaning messy text.

Enable the standard flags with one click: g global, i ignore case, m multiline, s dot-matches-newline, and u Unicode. Invalid patterns show the exact error instead of failing silently. Everything is evaluated locally on your device — paste sensitive logs or personal data without worry, because nothing is uploaded and the page works offline.

🌍 Which regex flavor is used?
JavaScript (ECMAScript). Syntax is mostly shared with other languages, but details like lookbehind support and \d meaning only ASCII digits differ elsewhere.

🧪 What do the flags do?
g finds all matches (without it, only the first); i ignores case; m makes ^/$ match line starts/ends; s lets . match newlines; u enables full Unicode mode.

⚠️ Why is my pattern “too slow”?
Nested quantifiers like (a+)+ can cause catastrophic backtracking. Prefer concrete alternatives such as [a-z]+ and test with short inputs first.

📋 How do I capture a group?
Wrap part of the pattern in parentheses, e.g. (\d{3})-(\d{4}). Each match row then lists group 1, group 2, and so on. Use (?:...) for non-capturing brackets.

🔒 Does this page run my regex on a server?
No. Matching happens entirely in your browser, with zero network calls, so nothing you test ever leaves your device.
