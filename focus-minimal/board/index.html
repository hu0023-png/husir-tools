Board

📘 About this tool

A distraction-free three-column task board — To Do, Doing, Done — for planning a day without feature overload. Type a task, press Add, then drag the card between columns as you make progress. Each column shows its count, so the workload is visible at a glance.

Tasks are saved in your browser (local storage) and stay private: no account, no sync servers, no uploads. Open the page tomorrow and your board is exactly where you left it.

🔒 Where are tasks saved?
Only on this device in the browser's local storage.

🖱️ How do I move a task?
Drag a card from one column and drop it into To Do, Doing, or Done.

📱 Does it work on a phone?
Yes — the layout is responsive; on narrow screens the three columns stack and cards can still be moved.

🌐 Does it need internet?
No — the board works fully offline once the page is open.

📈 When should I move a task to Done?
Move the card to Done the moment it is finished — the column counts give you a satisfying end-of-day summary.
