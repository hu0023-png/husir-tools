📘 About this tool

A free classroom toolkit with four helpers in one private page: a Name Picker for fair cold calls, a Scoreboard for points, a Countdown Timer for timed activities, and a Math Quiz with adjustable difficulty. Everything a teacher needs for a lesson stays in one tab — no signup and no student data upload.

Enter your class list once (one name per line) and the page remembers it on that device. Use pick history and pick counts to see who has been chosen, track points live, and save or export the list as a simple text file.

📋 How do I add my class list?
Type one name per line in the Student List box, then Save. You can also import a .txt or .csv file, and export the list later.

🎯 Does the picker avoid picking the same student twice?
It marks picked names and focuses on the remaining list, so you can keep choosing new students until you reset for the next round.

⭐ Where do scores live?
Only in your browser (local storage) — nothing is uploaded, which keeps minors' names private.

⏱️ Does the timer work for classroom activities?
Yes — set the minutes you need in the Countdown Timer tab and start it when the activity begins.

🌐 Does it work offline?
Yes — the whole toolkit runs in the browser with no internet needed.
